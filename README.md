# Gallary

A responsive React Gallery application built with **React, Vite, Tailwind CSS, Axios, and the Picsum Photos API**.

It fetches and displays images dynamically with responsive cards, pagination-based API requests, and interactive UI effects.

## 🚀 Features

- 📸 Fetch images dynamically from Picsum Photos API
- 🔄 Fetch data using Axios
- 📱 Fully responsive gallery
- 🎨 Styled with Tailwind CSS
- 🖼️ Responsive image cards
- 🔢 Pagination-based API requests
- ⚡ Built with React + Vite
- ✨ Interactive hover effects

## 🛠️ Technologies Used

- React
- Vite
- Tailwind CSS
- Axios
- Picsum Photos API
- JavaScript
- ESLint

🌐 API

This project uses the Picsum Photos API to fetch gallery images:

https://picsum.photos/v2/list

Example request:

https://picsum.photos/v2/list?page=5&limit=100
📷 Gallery

The application displays images in a responsive grid with author information and image IDs.
